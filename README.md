# SolidGames Launcher

Кастомный легковесный лаунчер для подключения к игровым серверам **Arma 3** проекта **SolidGames**. Разработан на платформе **.NET 10 (WPF)** и скомпилирован в единый переносимый файл (Single-file Portable `.exe`).

---

## ⚡ Основные возможности

### 🎮 Серверы и профили
* **Мониторинг онлайна в реальном времени:** опрос игровых серверов (Сервер 1 и Сервер 2) по протоколу Steam A2S_INFO (UDP).
* **Синхронизация профилей:** автоматическое обнаружение созданных профилей Arma 3 из папки документов пользователя.
* **Быстрое подключение:** автоматическая передача параметров подключения и выбранного профиля в `arma3battleye.exe`.

### 📦 Управление модами
Лаунчер автоматически формирует правильный порядок загрузки аддонов в командной строке (`-mod=`):
1. **Steam Workshop:** `@RHSAFRF`, `@RHSUSAF`, `@RHSGREF`, `@RHSSAF`, `@CUP Terrains - Core`
2. **Resilio Sync:** `@sg_core`, `@sg_islands`, `@sg_mods`
* **Автопроверка файлов:** лаунчер блокирует запуск при отсутствии обязательных модов Resilio во избежание крашей и ошибок синхронизации.
* **Интеграция с Resilio Sync:** детекция установленного клиента через реестр Windows (`rslsync`), копирование ключа раздачи в буфер обмена в один клик и пошаговая памятка по настройке.

### 🎙️ Интеграция с TeamSpeak 3 и TFAR
* **Умный поиск клиента:** обнаружение установленного TeamSpeak 3 в системе.
* **Автоподключение к TeamSpeak 3:** при запуске игры лаунчер автоматически подключает игрока на соответствующий сервер TS3 с игровым никнеймом.
* **Резервные IP:** возможность выбора адреса подключения TS3 (доменные имена `t1.sg.zone`/`t2.sg.zone` или прямой IP `87.58.213.152`) с сохранением выбора.
* **Установка рации:** быстрый переход к установке плагина Task Force Radio (`task_force_radio.ts3_plugin`) из скачанной папки `@sg_core` или по прямой ссылке с сайта.

### ⚙️ Параметры запуска игры и лаунчера
* **Параметры Arma 3:** выбор кастомного распределителя памяти (`-malloc`), отключение заставок (`-noSplash`), пропуск загрузки 3D-мира в меню (`-world=empty`), оконный режим (`-window`).
* **Параметры лаунчера:**
  * Закрытие лаунчера после старта игры.
  * Опциональная вкладка «Статистика» (`solid-stats.web.app`).
  * Запоминание положения и размера окна при перезапуске.

### 🌐 Встроенные веб-сервисы (WebView2)
* Просмотр расписания игр и анонсов с портала `sg.zone` без перехода в браузер.

## 🛠️ Сборка проекта из исходного кода

### Требования
* Visual Studio 2026 (или новее) с установленным компонентом **.NET Desktop Development**.
* SDK **.NET 10.0** (Windows).

### Публикация в единый `.exe` файл
Для сборки компактного независимого исполняемого файла выполните команду в консоли:

```bash
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:EnableCompressionInSingleFile=true /p:DebugType=none /p:DebugSymbols=false
```

Готовый файл будет находиться в директории:
`bin/Release/net10.0-windows/win-x64/publish/SolidGamesLauncher.exe`

## 📋 Порядок настройки для игроков

1. **Скачивание:** положите `SolidGamesLauncher.exe` в любое удобное место (например, на Рабочий стол).
2. **Моды Steam:** перейдите во вкладку **«МОДЫ»** и подпишитесь на коллекцию проекта в Steam Workshop.
3. **Моды Resilio:**
   * Установите Resilio Sync.
   * Нажмите кнопку **«2. СКАЧАТЬ МОДЫ ЧЕРЕЗ RESILIO»**, добавьте полученный ключ и выберите папку для сохранения.
   * Укажите эту папку кнопкой **«ВЫБРАТЬ ПАПКУ С МОДАМИ (RESILIO)»** в лаунчере.
4. **TeamSpeak:** во вкладке **«TEAMSPEAK 3»** скачайте клиент и установите плагин.
5. **Запуск:** во вкладке **«СЕРВЕРЫ»** выберите ваш игровой сервер, проверьте никнейм и нажмите **«ЗАПУСК»**.
