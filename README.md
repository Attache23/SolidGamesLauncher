# SolidGames Launcher

Лаунчер для подключения к игровым серверам **Arma 3** проекта **SolidGames**. Разработан на платформе **.NET 10 (WPF)** и скомпилирован в единый переносимый файл (Single-file Portable `.exe`).

---

## ⚡ Основные возможности

### 🎮 Серверы и профили
- **Мониторинг онлайна в реальном времени:** опрос игровых серверов (Сервер 1 и Сервер 2) по протоколу Steam A2S_INFO (UDP).
- **Синхронизация профилей:** автоматическое обнаружение созданных профилей Arma 3 из папки документов пользователя.
- **Быстрое подключение:** автоматическая передача параметров подключения и выбранного профиля в `arma3battleye.exe`.
- **Интерактивные оповещения:** если папка с модами ещё не выбрана, баннер предупреждения на вкладке серверов позволяет перейти к выбору папки в один клик.

### 📦 Управление модами (Встроенный Resilio Sync & Steam Workshop)
Лаунчер автоматически формирует правильный порядок загрузки аддонов в командной строке (`-mod=`):
1. **Steam Workshop:** `@RHSAFRF`, `@RHSUSAF`, `@RHSGREF`, `@RHSSAF`, `@CUP Terrains - Core` (выделены в отдельный блок для быстрой подписки в 1 клик).
2. **Resilio Sync:** `@sg_core`, `@sg_islands`, `@sg_mods`

#### 🚀 Автоматическая установка (Встроенный движок):
- **Загрузка в 1 клик:** встроенный движок Resilio Sync (2.7.3) работает полностью в фоновом режиме.
- **Автоматическая конфигурация:** лаунчер сам отключает архивацию старых файлов (`use_sync_trash: false`), включает автоперезапись изменённых файлов.


#### 🛡️ Контроль целостности:
- **Защита от запуска с недокачанными файлами:** лаунчер отслеживает временные файлы (`.!sync` / `.rsls`) и общий вес директории, блокируя запуск неполной сборки во избежание крашей игры.
- **Детектор сторонних `.sync`:** проверка наличия конфликтующих баз данных от внешних клиентов Resilio с предложением безопасной автоочистки.
- **Умный автопоиск:** автоматическое сканирование всех доступных дисков системы на наличие ранее установленных модов SolidGames.
- **Ручная установка:** сохранена альтернативная возможность использовать стандартный внешний клиент Resilio Sync с готовой памяткой по настройке.

### 🎙️ Интеграция с TeamSpeak 3 и TFAR
- **Умный поиск клиента:** автоматическое обнаружение установленного TeamSpeak 3 в системе.
- **Автоподключение к TeamSpeak 3:** при запуске игры лаунчер автоматически подключает игрока на соответствующий сервер TS3 с игровым никнеймом.
- **Резервные адреса:** возможность выбора адреса подключения TS3 (доменные имена `t1.sg.zone`/`t2.sg.zone` или прямой IP `87.58.213.152`) с сохранением выбора.
- **Установка рации:** быстрый запуск инсталлятора плагина Task Force Radio (`task_force_radio.ts3_plugin`) через нативный `package_installer.exe` TeamSpeak.

### ⚙️ Параметры запуска игры и лаунчера
- **Параметры Arma 3:** выбор кастомного распределителя памяти (`-malloc`), отключение заставок (`-noSplash`), пропуск загрузки 3D-мира в меню (`-world=empty`), оконный режим (`-window`).
- **Параметры лаунчера:**
  - Закрытие лаунчера после старта игры.

## 🛠️ Сборка проекта из исходного кода

### Требования
- Visual Studio 2026 (или новее) с установленным компонентом **.NET Desktop Development**.
- SDK **.NET 10.0** (Windows).

### Публикация в единый `.exe` файл
Для сборки компактного независимого исполняемого файла выполните команду в консоли:

```bash
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:EnableCompressionInSingleFile=true /p:DebugType=none /p:DebugSymbols=false
```

Готовый файл будет находиться в директории:
`bin/Release/net10.0-windows/win-x64/publish/SolidGamesLauncher.exe`

## 📋 Порядок настройки для игроков

1. **Запуск:** положите `SolidGamesLauncher.exe` в любое удобное место и запустите.
2. **Моды Steam Workshop:** во вкладке **«МОДЫ»** в верхнем блоке нажмите **«ПОДПИСАТЬСЯ В STEAM WORKSHOP»**.
3. **Моды сборки (Resilio):**
   - **Автоматически (рекомендуется):** нажмите **«СКАЧАТЬ МОДЫ»**, укажите папку на диске — лаунчер сам загрузит и настроит всю сборку модов.
   - **Вручную (альтернатива):** воспользуйтесь нижним блоком «РУЧНАЯ УСТАНОВКА» и ключом раздачи.
4. **TeamSpeak 3:** во вкладке **«TEAMSPEAK 3»** убедитесь, что клиент найден, и установите плагин TFAR.
5. **Вход в игру:** во вкладке **«СЕРВЕРЫ»** выберите сервер (Сервер 1 / Сервер 2), проверьте профиль и нажмите **«ЗАПУСК»**.
